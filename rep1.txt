The MCP spec requires the agent host to obtain explicit human consent before invoking any tool, which is why the consent prompt appeared when get_disk_usage was triggered. The spec also treats tool descriptions from untrusted servers as untrusted input to prevent a malicious or misconfigured server from tricking the agent into unsafe actions.
