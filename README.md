# Week 15 — AIOps and Autonomous Operations  
System Administration & Maintenance (CSC 6400)

This repository contains my completed work for Week 15, where the lab itself serves as the assignment.  
The goal of this week was to build, run, and evaluate a gated self‑healing loop using MCP tools, an approval gate, and a simulated disk‑pressure incident.

## Contents
- **Reps 1–11** — All required steps, including MCP setup, resource inspection, approval‑gate testing, autonomy‑tier analysis, guardrail mapping, and full-loop execution.
- **audit.log** — The gate’s recorded decisions showing blocked destructive actions and allowed read‑only operations.
- **agent-log.txt** — My professional AI‑usage statement documenting where Copilot assisted and where human judgment remained primary.
- **governance.txt** — A 250‑word autonomy policy including an autonomy ladder, gated actions, Rule‑of‑Two, audit requirements, and a cost cap.

## Summary
All MCP tools were wired correctly, the approval gate behaved as expected, and the full remediation loop was executed with and without the gate to demonstrate safe vs. unsafe outcomes.  
Every decision, tier placement, and reflection was written by me, with Copilot used only for clarity and structure—not for authoring technical judgments.
